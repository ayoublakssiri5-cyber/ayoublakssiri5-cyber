## Selected projects

### 💳 [CentrePay](https://github.com/ayoublakssiri5-cyber/centrepay-android) — Android · Java · SQLite

- Transactions with rollback and schema migrations without data loss.
- **40 unit tests** (JUnit, Robolectric on a real SQLite database).

- **61 PHPUnit tests** and GitHub Actions CI on PHP 8.2, 8.3 and 8.4.

### 🫁 [Pneumonia Detector](https://github.com/ayoublakssiri5-cyber/pneumonia-detector) — Python · TensorFlow/Keras · FastAPI

Pneumonia detection from chest X-ray images with ResNet50 transfer learning, Grad-CAM explanations, a FastAPI backend and a web interface. Results reported in the project README: 93.33% accuracy and 0.9867 AUC-ROC on the test set.
